PLATA STUDIO — sitio web personal

Archivos:
- index.html: estructura de la página.
- styles.css: diseño adaptable para computador, tablet y celular.
- script.js: menú móvil, animaciones de entrada y galería ampliable.
- assets/: fotografías originales y logotipo aportados por Miguel.

Cómo abrir:
1. Descomprime la carpeta.
2. Abre index.html en un navegador moderno.
3. Para publicar, sube toda la carpeta manteniendo la estructura de archivos.
